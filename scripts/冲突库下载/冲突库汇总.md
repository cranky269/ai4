> 隔离目录：`lib/m4/`（约 1.1 GB，已写入 `.gitignore`，**不入库**）
> 隔离下载脚本：`scripts/冲突库下载/install_m4_deps.sh`

**冲突原因**

- `ultralytics`（YOLOv8）元数据要求 `numpy>=1.18.5`（实测 8.4.174 要求 `>=1.23.0`），而工程基线 `requirements.txt` 锁 `numpy==1.17.4`（ROS Noetic / `cv_bridge` / `scipy 1.8.1` 依赖），直接 pip 安装会升级系统 numpy、破坏基线；
- `opencv-python` 会遮蔽系统 `cv2 4.2.0`，与 `cv_bridge` 版本错配。
- 故按《项目要求汇总.md》Q4/A4 采用**隔离下载**：全部装进 `lib/m4`，由节点通过 `PYTHONPATH` 注入，系统包一律不动。因此以下库**不写入 `requirements.txt`**。

**下载指令（统一入口，推荐）**

```bash
# <DIR> = lib/m4
bash scripts/冲突库下载/install_m4_deps.sh              # 安装（约 300 MB 下载 / 1.1 GB 占用）
bash scripts/冲突库下载/install_m4_deps.sh --check      # 只检查现状，不安装
bash scripts/冲突库下载/install_m4_deps.sh --uninstall  # 删除 lib/m4（系统不受影响）
```

**外来库清单（名字 / 版本 / 下载指令）**

| 库 | 版本 | 下载指令 |
| --- | --- | --- |

| ultralytics | 8.4.174 | `pip3 install --target=<DIR> --index-url https://mirrors.aliyun.com/pypi/simple/ --no-deps ultralytics` |
| ultralytics-thop | >=2.2.2 | `pip3 install --target=<DIR> --index-url https://mirrors.aliyun.com/pypi/simple/ --no-deps "ultralytics-thop>=2.2.2"` |
| numpy | 1.21.6（仅隔离目录内） | `pip3 install --target=<DIR> --index-url https://mirrors.aliyun.com/pypi/simple/ --no-deps --upgrade "numpy==1.21.6"` |
| matplotlib / pillow / pyyaml / requests / psutil / polars / nvidia-ml-py | >=3.3.0 / >=7.1.2 / >=5.3.1 / >=2.23.0 / >=5.8.0 / >=0.20.0 / >=12.0.0（ultralytics 运行时依赖，显式列出，不含 torch/numpy/opencv） | `pip3 install --target=<DIR> --index-url https://mirrors.aliyun.com/pypi/simple/ "matplotlib>=3.3.0" "pillow>=7.1.2" "pyyaml>=5.3.1" "requests>=2.23.0" "psutil>=5.8.0" "polars>=0.20.0" "nvidia-ml-py>=12.0.0"` |
| opencv-python | **不安装**（若被拖入则删除） | `rm -rf <DIR>/cv2 <DIR>/cv2-* <DIR>/opencv_python*`（保留系统 `cv2 4.2.0`） |

**隔离验证**

- `PYTHONPATH=<DIR> python3 -c "import numpy;print(numpy.__version__)"` → `1.21.6`
- `python3 -c "import numpy;print(numpy.__version__)"` → 仍为 `1.17.4`（系统未动）
- 仅 `/detector` 节点把 `<DIR>` 注入 `sys.path`，其他节点只加 `lib/`，取不到隔离依赖。
