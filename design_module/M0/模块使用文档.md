# M0 使用

以下命令均从 **ai4 根目录的普通 Ubuntu Bash 终端**执行，需要可访问的图形桌面和本地 socket。2026-11-08 已通过真实 Gazebo、独立物理步真值、连续画面、新终端录制及新数据回读验证。当前机器仿真慢于墙钟时间，60 秒墙钟不等于 60 秒仿真。

## 首次准备

已具备 ROS Noetic、Gazebo 11 和项目系统依赖后：

```bash
bash scripts/冲突库下载/install_m0_deps.sh --check
source /opt/ros/noetic/setup.bash
catkin_make -C catkin_ws -DPYTHON_EXECUTABLE=/usr/bin/python3 -j2
bash catkin_ws/src/uav_sim/scripts/start_mounted_radar.sh --check-env
```

首次缺少隔离包时运行 `bash scripts/冲突库下载/install_m0_deps.sh`；依赖安装在 `lib/venv/sensor_python`，不改系统 Python。已有目录但检查失败时先检查缺包，不删除或覆盖环境。

## 一键启动

```bash
bash catkin_ws/src/uav_sim/scripts/start_mounted_radar.sh
```

等待双机、相机和雷达点云持续更新；不要重复启动。点云窗口固定参考系为 `world`。

## 新终端查看与录制

查看观测无人机世界位姿：

```bash
bash catkin_ws/src/uav_sim/scripts/sensor_live.sh pose
```

同时录制点云和逐扫描位姿：

```bash
bash catkin_ws/src/uav_sim/scripts/sensor_live.sh record
```

两个入口均自动连接当前活动实例，无需填写运行目录。bag 保存到 `data/radar/radar_pose_*.bag`，终端打印本次完整路径。多个活动实例时按入口提示显式选择。

`/radar/points` 的 **XYZ 是回波点在 world 中的位置**；`/radar/uav_pose_world` 的 **position 是观测无人机模型参考点在 world 中的位置**，不是雷达中心或目标机。单位均为米，姿态为机体相对 world 的四元数。两者按相同采样时间戳配对；遇时间回退按 epoch 分段，禁止跨 epoch 配对。

需要同时保存逐帧 NPZ、图片及 epoch 索引时，在停止现有仿真后启动：

```bash
bash catkin_ws/src/uav_sim/scripts/start_mounted_radar.sh record:=true
```

保存到终端打印的 `data/radar/<本次运行目录>`，包含 `raw.bag`、`frames/*.npz`、`frames.csv`、`radar_poses.csv` 和相机图片。

## 停止与排错

先在录制终端按 **Ctrl+C**，等待 bag 保存完成；再在启动终端按 **Ctrl+C** 停止仿真。查看终端也用 Ctrl+C。不要全局杀 ROS/Gazebo。

- 无活动实例：先启动并等待就绪；用下面命令检查。停止后的旧实例应被拒绝。
- socket 被拒绝或显示不可达：改用有本地网络与桌面权限的普通 Ubuntu 终端；不反复启动。
- 缺包：运行首次准备中的检查命令；启动日志在本次目录的 `console.log` 和 `ros/`。
- 点云查看：固定系保持 world，鼠标中键平移、滚轮缩放；历史 `radar_link` 数据不能直接当 world 回放。

```bash
bash catkin_ws/src/uav_sim/scripts/sensor_live.sh list
```

## 测试

离线回归（不能替代真实仿真）：

```bash
source /opt/ros/noetic/setup.bash
source catkin_ws/devel/setup.bash
source lib/venv/env.bash
/usr/bin/python3 test/uav_sim/radar_pose/test_active_run.py
/usr/bin/python3 test/uav_sim/radar_pose/test_world_recording.py
```

真实坐标回归：先正常停止当前仿真，再执行；自动创建本轮目录，无需手工替换路径。

```bash
source /opt/ros/noetic/setup.bash
source catkin_ws/devel/setup.bash
source lib/venv/env.bash
M0_AUDIT_BUILD=$(mktemp -d)
cmake -S test/uav_sim/radar_pose -B "$M0_AUDIT_BUILD"
cmake --build "$M0_AUDIT_BUILD" -j2
M0_CHECK_RUN="data/radar/world_validation_$(date +%Y%m%d_%H%M%S)"
/usr/bin/python3 test/uav_sim/radar_pose/run_gazebo_check.py "$M0_CHECK_RUN" "$M0_AUDIT_BUILD/libmodel_pose_audit.so"
/usr/bin/python3 test/uav_sim/radar_pose/compare_model_pose.py "$M0_CHECK_RUN"
/usr/bin/python3 test/uav_sim/radar_pose/check_actual_scans.py "$M0_CHECK_RUN"
```

该测试覆盖平移、旋转、非零安装偏移及时间重置；双机和 GUI 效果仍应从正式启动入口检查。

## 本轮实测与边界（2026-11-08）

独立物理步真值185对位姿全部匹配；186帧有回波扫描共42132点，world XYZ最大误差9.463e-7米，另25空回波帧单列。正式录制1028帧点云及位姿回读通过，新终端bag 67对通过；连续画面及图形回读已验证。实时因子约0.18–0.20，当前结果属于M0验证，不代表M3验收。原始证据留在本地 `data/radar/acceptance_20261108_0420`，不随代码提交。
