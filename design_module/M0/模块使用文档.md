# M0 模块使用文档

所有命令均在 ai4 项目根目录的 Bash 终端执行。需要已安装 ROS Noetic、Gazebo 11 及项目声明的系统依赖，并可打开图形桌面。

## 首次准备

```bash
source /opt/ros/noetic/setup.bash
catkin_make -C catkin_ws -DPYTHON_EXECUTABLE=/usr/bin/python3 -j2
bash scripts/冲突库下载/install_m0_deps.sh
```

隔离 Python 依赖保存在 `lib/venv/sensor_python/`；构建或依赖改变后重新执行准备命令。

## 启动

```bash
bash catkin_ws/src/uav_sim/scripts/start_mounted_radar.sh
```

等待 Gazebo 和相机/点云查看器打开，两机运动后使用。默认不录制，不重复启动。

## 新终端查看世界位姿

```bash
bash catkin_ws/src/uav_sim/scripts/sensor_live.sh pose
```

自动连接活动实例。`/radar/uav_pose_world` 是观测无人机模型原点的世界位置（米）和姿态四元数（xyzw），与点云同帧采样；不是目标机位置。`/radar/points` 的 XYZ 和 frame_id 均为 `world`，range 仍是雷达测距。world 为 Gazebo 固定场景坐标，右手系、z 向上，x/y 为场景轴。

## 新终端录制

```bash
bash catkin_ws/src/uav_sim/scripts/sensor_live.sh record
```

同时录制点云和观测机位姿，打印实际 bag 路径；保存在 `data/radar/radar_pose_时间戳.bag`。两话题按完全相同的 `header.stamp` 配对；时间回退时分段。启动时追加 `record:=true` 可沿用内置相机/点云记录器，其数据保存在 `data/radar/` 的本次实例目录，正常关闭后可由离线查看器回读。历史局部坐标录制不能作为 world 点云使用。

## 停止和排错

先在录制终端按 **Ctrl+C**，等待 bag 保存完成；再退出位姿查看，最后在启动终端按 **Ctrl+C**，等待本实例退出。

没有活动实例时先启动并等待就绪；列出活动实例：

```bash
bash catkin_ws/src/uav_sim/scripts/sensor_live.sh list
```

多个实例时使用入口打印的完整选择命令。启动失败时查看启动终端，以及其打印的实例目录中的 `console.log`、`startup_error.txt`。提示缺少依赖或插件时重新执行首次准备；提示已有 gzserver 时先正常停止其所属实例。
