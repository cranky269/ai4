# M0 模块使用文档

## 必要准备

需要实际桌面、ROS Noetic、Gazebo Classic 11、系统 Python 3.8、PyQt5、RViz、Pillow 和项目 ROS 依赖。隔离依赖未安装时，在项目根目录执行 `bash scripts/冲突库下载/install_m0_deps.sh`；首次使用或 C++ 源码更新后构建：

```bash
source /opt/ros/noetic/setup.bash && catkin_make -C catkin_ws -DPYTHON_EXECUTABLE=/usr/bin/python3 -j2
```

## 启动

在 **ai4 项目根目录**的一个 Bash 桌面终端执行：

```bash
bash catkin_ws/src/uav_sim/scripts/start_mounted_radar.sh
```

## 正常效果（检查标准）

- Gazebo 中两机同时清晰可见、无遮挡；观测机持续移动，绿色目标机持续八字运动，仿真时间递增。
- **AI4 Camera + 3D Radar | LIVE** 窗口显示相机与真实点云，目标图像及对应回波随运动变化，两路时间戳递增。
- 默认相机320×240、10仿真Hz，雷达181×25射线、5仿真Hz；默认不录制。墙钟速度取决于机器性能，历史实测约0.30倍实时。

## 停止

在启动终端按 **Ctrl+C**，等待所属进程退出。不要全局杀死 ROS/Gazebo。

## 极简排错

提示已有实例：先在原启动终端停止。依赖异常：执行 `bash scripts/冲突库下载/install_m0_deps.sh --check`。启动超时或数据停滞：查看本次 `data/radar/<运行目录>/console.log` 和 `startup_error.txt`（出错时生成）。黑色遮挡或两机不可见时，显示验收未通过；健康文件不能代替实际画面。
