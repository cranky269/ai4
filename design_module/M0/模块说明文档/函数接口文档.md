# M0 函数接口文档

## 范围和约定

本文对应当前源码，不更改design/中既有接口。路径均相对于项目根目录；米、弧度、秒为默认单位，ROS时间为仿真时间，墙钟另外注明。描述已有接口不代表本轮调用或验收；相机、雷达接口仅核对源码。

## 启动与环境接口

| 接口 | 输入与默认值 | 输出、副作用和失败 |
| --- | --- | --- |
| start_mounted_radar.sh | scene_only:=false；--check-env默认关闭；其余参数转发launch | 默认启动实时传感器模式、不录制；record:=true显式启用记录；sensor_profile:=desktop默认相机320×240/10Hz，full恢复640×480/15Hz；scene_only:=true启动双机；检查模式只导入并打印，导入失败非零退出 |
| 环境变量 | AI4_CLUSTER_PYTHON默认系统Python；RADAR_CONFIG默认catkin_ws/src/uav_sim/config/radar_3d.yaml | 显式解释器覆盖保留；config为生成世界参数来源；OPENBLAS/OMP/MKL线程限制为1 |
| lib/venv/env.bash | source调用，无参数 | 动态推导sensor_python并前置到PYTHONPATH，避免重复添加；目录缺失时不添加，由后续导入检查报错 |
| install_m0_deps.sh | --check只检查；无参数首次安装；其他参数错误 | 读取lib/venv/requirements.txt，目标目录已存在时不覆盖；缺失时pip --target安装；安装后运行原入口--check-env |

入口依赖catkin_ws/devel/setup.bash及原系统ROS。--check-env在获取锁及分配端口前退出。实例锁及已有gzserver保护适用于真实启动，避免误停其他运行。

## 世界准备与运动函数

源文件catkin_ws/src/uav_sim/scripts/prepare_mounted_radar.py：

- prepare(root, output, config, markers=False, scene_only=False, sensor_profile='full')：root/output接受Path可转换的路径，config为YAML路径；返回配置dict。生成output下mounted.world、radar.yaml、run.json。markers选择基础世界；scene_only仅在生成模型中去掉sensor节点。无效采样数、角度、数值或范围抛ValueError；文件缺失、字段缺失也会报错，不生成伪成功状态。采样数每轴须为整数2–65535，总射线不超过1000000；角度有序且处于允许区间；配置数值均有限，范围与更新率等须有效。并非所有数值参数都有完整类型约束，不应把配置校验称为形式化验证。

源文件catkin_ws/src/uav_sim/scripts/camera_motion_demo.py：

| 函数/方法 | 输入 | 返回与行为 |
| --- | --- | --- |
| smooth(a,b,t) | 数值起终点与插值比例 | 先将t限于[0,1]，返回三次平滑插值a+(b-a)t²(3-2t) |
| path(t) | 墙钟经过秒 | 返回(phase,(x,y,z,yaw))，按源码执行保持、横移、前后移动及偏航，22秒起final_hold，Demo在26秒结束非连续演示 |
| Demo.coordinates() | 无；要求actual已有效 | 返回实际(x,y,z,yaw)，yaw=2atan2(qz,qw)，适用于当前仅绕z轴模型 |
| Demo.loop() | 无；读取~continuous，默认false | 持续服务读写、发布实际pose/状态/TF；连续模式使用仿真时钟轨迹，非连续模式按mode选择演示或回原位 |
| Demo.run/stop/home/status(_) | TriggerRequest，无有效载荷 | 返回TriggerResponse(success,message)，具体见下表 |

目标源码catkin_ws/src/uav_sim/scripts/figure_eight_target.py：FigureEightTarget.__init__读取model_name、center_x/y、height、scale_x/y、period、update_rate。类默认height=0.6，mounted入口明确使用1.42，二者不要混同。比例、周期、更新率和高度需正且有限；cx-ax>=1、高度>=0.2，否则ValueError。clock(msg)更新当前仿真时间并检测回退；pause(request)维护暂停及相位；run()等待三个Gazebo服务、生成模型并按仿真时间写入八字，随后GetModelState发布真实位姿。生成或服务返回失败报错；部分服务传输异常记录警告并重试。run()不是有限时长返回的函数。

## ROS服务接口

| 服务名 | 类型 | 请求/响应及限制 |
| --- | --- | --- |
| /camera_motion_demo/run | std_srvs/Trigger | 仅idle且已读取实际位置、接近(0,0,0.12,0)时接受；否则success=false。是旧非连续演示接口 |
| /camera_motion_demo/stop | std_srvs/Trigger | 设置mode=idle；连续模式loop优先使用continuous，不能用它停止连续轨迹；停止本次演示应在所属终端Ctrl+C |
| /camera_motion_demo/home | std_srvs/Trigger | 限制旧演示区域，3秒平滑回(0,0,0.12,0)；连续飞行高度不满足其前置条件 |
| /camera_motion_demo/status | std_srvs/Trigger | success=true，message为状态JSON；连续模式elapsed_wall_s字段实际存仿真秒 |
| /target/pause | std_srvs/SetBool | data=true暂停目标写入，false恢复并补偿相位；不暂停Gazebo物理或观测机 |
| /gazebo/get_model_state | gazebo_msgs/GetModelState | 输入model_name和relative_entity_name=world；返回实际pose/twist及success/status_message |
| /gazebo/set_model_state | gazebo_msgs/SetModelState | ModelState设置model_name、world位姿，默认零twist；必须检查success |
| /gazebo/spawn_sdf_model | gazebo_msgs/SpawnModel | 目标SDF、模型名称、初始pose及world参考系；必须检查success |

上述服务名称是运行时ROS名称，不是文件系统绝对路径。本轮未发送运动或暂停服务请求。

## ROS话题和坐标接口

| 话题 | 类型 | 来源及消费用途 |
| --- | --- | --- |
| /clock | rosgraph_msgs/Clock | Gazebo→目标时钟及ROS仿真时间 |
| /camera_motion_demo/actual_pose | geometry_msgs/PoseStamped | GetModelState实际观测机pose，frame=world |
| /camera_motion_demo/state | std_msgs/String | Demo状态JSON，latched |
| /target/expected_pose | geometry_msgs/PoseStamped | 目标期望命令，不能替代真实位姿 |
| /target/ground_truth/pose | geometry_msgs/PoseStamped | GetModelState返回的实际目标pose，frame=world |
| /tf、/tf_static | tf2_msgs/TFMessage | world→uav_base_link；相机固定安装与光学变换；完整模式增加radar_link |
| /uav/front_camera/image_raw、/uav/front_camera/camera_info | sensor_msgs/Image、CameraInfo | 源相机，仅保留完整模式 |
| /camera/image_raw、/camera/camera_info | sensor_msgs/Image、CameraInfo | sensor_interfaces原消息别名，保留头与数据 |
| /target/pose | geometry_msgs/PoseStamped | 真值别名，用于调试，不作为雷达测量 |
| /radar/points | sensor_msgs/PointCloud2 | 原生扫描桥接，frame=radar_link；完整模式送记录/聚类等 |
| /radar/centroid | uav_tracking/CentroidArray | 记录器订阅的下游聚类接口，元素为PointStamped；本轮未核验发布结果 |

RayCloudBridge默认gazebo_topic是地面雷达路径；mounted_radar.launch将其改为/gazebo/base_scene/static_uav/base_link/ray_3d/scan。frame_id默认radar_link，cloud_topic默认/radar/points，require_recorder在mounted中跟随record参数（默认false）。该等待条件实际检查有订阅者，不校验订阅者身份。

OnScan(message)输入Gazebo LaserScanStamped，检查二维数量与ranges数量吻合，然后按角度转XYZ。Put<T>写原生字节；无额外噪声。非法扫描记录错误后丢弃。字段、无效值与坐标语义见数据类型文档。

## 记录和退出接口（保留但未验收）

record_radar.py的save_cloud(path,msg)按PointField布局保存NPZ并返回有限XYZ点数；大/小端由消息标识决定。Recorder.receive(msg,topic)入队，队列溢出触发shutdown并记录丢失；write_loop()独占写bag和逐帧文件；close()停止接收、排空并写statistics.json。backpressure()在磁盘队列高时暂停仿真，队列降下后恢复。

sensor_interfaces.py的Interfaces.receive(m)写源序号索引并原样发布图像；close()取消图像订阅并关闭文件。sensor_session.py是命令行顶层程序，输入运行目录和后续roslaunch命令，接管所属子进程组及退出状态。check_mounted_motion.py也为顶层程序，输入已完成传感器运行目录，写mounted_verification.json与target_echo_check.csv；它依赖图像和雷达数据，不适用于仅场景产物，本轮不执行。

## 本轮启动修复补充

start_sensor_clock.py以150秒上限等待组件ready，再有界调用unpause；120秒内要求时钟、两路传感器各出现至少两个不同时间戳，以及两机实际位姿变化。运行中未暂停但流超过20墙钟秒不推进会明确报错并关闭本次launch。暂停状态只告警等待恢复，不自行覆盖用户或记录器暂停。native_gzclient.sh等实际模型存在再启动GUI，整个等待受180秒timeout约束。查看器用最新帧合并和10Hz图像显示调度（RViz通过Global Options将Frame Rate设为10），窗口发现/布局放在独立进程，默认不自动截图；原手动Save view保留。

RayCloudBridge和Audit新增~world_name私有参数，默认base_scene；Gazebo transport Node显式以该命名空间Init，避免在真实世界创建之前注册default并让GUI连接空世界。需要其他世界时应同时配置现有绝对Gazebo话题，不只改一个参数。

## 雷达逐帧位姿增量接口

机载模式新增 `/radar/uav_pose_world`（`geometry_msgs/PoseStamped`），与原 `/radar/points` 使用同一原生采样时间戳。私有参数、固定安装链、缺失处理和重置约定见同目录 `雷达逐帧世界位姿.md`；原异步位姿话题和点云接口均保留。

## 新终端活动实例入口

`sensor_live.sh pose|record|list [--run 实例名]` 从脚本位置定位项目，加载 ROS/catkin 环境；通过 `find_active_sensor_run.py` 验证各 connection.bash 所指 master 的运行目录身份、消息类型及发布节点存活，再加载唯一选中实例的连接配置，并等待两个话题实际采样。pose 执行 rostopic echo；record 显式录制点云与位姿到项目 data/radar，打印唯一 bag 路径。无实例明确提示启动，多实例拒绝猜测并输出带实际实例名的完整选择命令。

内部 `connection_env(path)` 解析启动器导出的连接参数；`inspect_run(run)` 通过有界 XMLRPC 检查身份和发布者；`discover(data_root)` 返回活动实例及排除原因，不按目录时间选择。离线辅助 `test/uav_sim/radar_pose/check_live_bag.py` 回读正常关闭的 bag，按各话题时间回退划分 epoch 后精确配对，输出消息数、缺失及样例。
