# M0 传感器记录数据类型

## 1. ROS接口（复用，不新建业务类型）

| 话题 | 消息 / frame | 处理 |
| --- | --- | --- |
| /radar/points | sensor_msgs/PointCloud2 / radar_link | 复用原桥接，组织化height=5,width=181；x/y/z/range float32米，ring/column uint16，status uint8；point_step=24 |
| /camera/image_raw | sensor_msgs/Image / uav_camera_optical_frame | 原 /uav/front_camera/image_raw 原像素及stamp别名，640×480 rgb8 |
| /camera/camera_info | sensor_msgs/CameraInfo | 原相机标定消息别名 |
| /radar/centroid | uav_tracking/CentroidArray | 上游cluster原算法输出 |
| /target/pose | geometry_msgs/PoseStamped / world | 已有真值debug别名，不替代雷达 |

本次不新增ROS msg或公共算法dataclass，原code/datatypes.py不变。

## 2. 逐帧存储定义

NPZ每个x/y/z/range为(5,181) float32；无效XYZ为NaN；量程边界若被原桥接判为有效则保留XYZ，原range的inf/NaN保留。ring/column为同形uint16、从0起，status同形uint8：0无回波、1内部有效、2低于最小量程、3/4量程边界。valid同形bool，表示XYZ均有限。stamp_sec/stamp_nsec为原ROS时间整数标量，frame_id字符串radar_link。frames.csv字段：frame（本地0起序号）、seq（源header）、stamp_sec、stamp_nsec、frame_id、valid_points（有效点数）、file（相对路径）。

camera_frames.csv：frame（本地0起）、source_seq（源header序号）、stamp_sec/stamp_nsec、frame_id、encoding、width/height、file。PNG为原图无损像素；bgr8转RGB保存，mono8保持灰度。不同传感器的本地frame不表示同步。

source_sensor_stamps.csv记录sensor(camera/radar)、stamp_sec/stamp_nsec；相机同一测量时间的暂停重复渲染只记一次。camera_publisher.csv记录source_seq/stamp_sec/stamp_nsec/frame_id。cluster_received.csv记录seq/stamp_sec/stamp_nsec/frame_id/finite_points/clusters；最后一列在新仿真适配器中空置，不伪造簇数。

## 3. 状态及完整性

run.json记录created_utc、root、config、markers和状态。prepared_only不代表采集成功；正常关闭后为closed_pending_verification，实际校验另见sensor_verification.json。statistics.json记录status(closed/failed)、start/end_utc、radar_frames、camera_png_frames、valid_points、各topic_messages、first/last_sim_time、实测频率以及queue_drops/sequence_gaps/timestamp_gaps/write_errors和错误数组。四种错误计数必须为0。

sensor_verification.json中的camera_complete/radar_complete/cluster_complete必须均true；all_png_pixels_exact、源/发布/bag/逐帧数和差额用于复核。verify失败或bag修改后结果过期，查找器不认作最新完整记录。shutdown.json记录pause_returncode和输出；launcher_exit_code.txt为整数。interfaces/mapping.json明确detector仅暂存，目录命名不意味着节点实际接收。

## 4. 坐标和时间

机载radar相对uav_base_link平移(0.30,0,0.12)m、单位四元数；相机光学frame安装关系保留上游TF。移动点云转换到world需使用同一测量时刻TF，不能直接把radar_link当世界系。离线界面使用两路原测量时间选最近帧并显示差值，回放显示master时钟独立于可倒退的测量时间。
