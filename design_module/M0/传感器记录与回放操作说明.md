
前台打印本轮唯一目录 `$AI4_ROOT/data/radar/YYYYMMDD_HHMMSS_UUID/`，所有 bag、PNG、NPZ、索引、配置和日志归于本轮。失败轮次也保留，不能用“最新文件夹”代表成功。入口拒绝已有 gzserver，不停止其他实例。

Gazebo显示双机；联合窗口左边是真实机载相机，右边是原生三维点云，雷达坐标 radar_link，米，X前Y左Z上；左键旋转、滚轮缩放、中键平移，可切换高度或距离着色。目标保持12仿真秒8字，观测机复用26墙钟秒位姿预设并重复。传感器时钟相同但频率不同，窗口显示帧号和时间差，不保证严格同步。


## 4. 相机、点云逐帧查看与回放

```bash
bash "$AI4_ROOT/catkin_ws/src/uav_sim/scripts/open_sensor_run.sh" "$RUN"
```

无需当前仿真，入口启动自己的 ROS master；Camera frames 查看每张相机帧，Radar frames 查看每帧点云。按钮或左右键上/下一帧；空格播放/暂停，滑块跳转；按原测量时间差调度播放，另一传感器选最近时间帧。点云支持旋转、缩放、平移；状态栏显示两个原始仿真时间和差值。

独立显示 master 使用墙钟，避免倒退测量时间使 RViz 清空点云；点云 header 与状态栏保留原测量时间，不改采集文件。回放使用 `/viewer/points`，不冒充在线 `/radar/points`。关闭窗口或 Ctrl+C 后只停止本入口的 master。只读原始数据不变；新增 replay 日志和 viewer_evidence 证据。

ROS接口回放需在另一独立 master 中启动实际接收节点：

```bash
rosbag info "$RUN/raw.bag"
# 在隔离的回放master中设 use_sim_time=true，启动实际接收节点后执行：
rosbag play --clock "$RUN/raw.bag"
```

bag 中 `/camera/image_raw` 为 sensor_msgs/Image，frame=uav_camera_optical_frame；`/radar/points` 为 PointCloud2，frame=radar_link。detector 代码及 launch 已在上游存在，但本组合未启动该节点、未验证模型权重和接收；`interfaces/node__detector` 仅本地暂存，不是已完成接入。不得同时把实时源与bag接入同一master。
