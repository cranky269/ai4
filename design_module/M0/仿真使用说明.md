# ai4

ROS Noetic / Gazebo Classic 11 无人机教学仿真与既有算法模块。仿真演示以运动学位姿驱动为主，不代表飞控闭环飞行；本次整理不扩展识别、跟踪、规划或避障功能。

## 环境与构建

Ubuntu 20.04、ROS Noetic、Gazebo Classic 11，使用系统 Python 3 构建。依赖需事先准备，脚本不会自动安装。算法 Python 依赖见 [requirements.txt](../../requirements.txt)；算法检查可使用仓库根目录 `.venv`，且需可导入 ROS 包。

从仓库根目录执行：

```bash
source /opt/ros/noetic/setup.bash
cd catkin_ws
catkin_make -DPYTHON_EXECUTABLE=/usr/bin/python3 -j2
source devel/setup.bash
cd ..
```

## 已有演示入口

运行前先检查已有实例，复用现有窗口；不要并行启动多个 Gazebo 演示。启动脚本打印独立的 ROS/Gazebo master 地址，查询或控制必须连接同一实例。

```bash
# 静态无人机及红蓝标志物相机场景
bash catkin_ws/src/uav_sim/scripts/start_static_scene.sh
# 8字目标无人机，关闭标志物，并打开真实机载相机窗口
bash catkin_ws/src/uav_sim/scripts/start_static_scene.sh gui:=true dynamic_target:=true markers:=false
# 独立三维Ray观测演示：与上述场景择一启动
bash catkin_ws/src/uav_sim/scripts/start_radar_3d.sh
```

观测机 `static_uav` 的相机话题为 `/uav/front_camera/image_raw`；目标机 `target_uav` 复用 Iris 网格，默认周期 12 仿真秒。观测机运动服务 `/camera_motion_demo/run`、`stop`、`home`、`status` 移动整个机体；目标 `/target/pause` 接受 `std_srvs/SetBool`。在静态场景启动日志目录找到本轮 `connection.bash`，另一个终端加载 ROS 与该文件后调用服务：

```bash
source /opt/ros/noetic/setup.bash
# source reports/static-scene-runs/<本轮目录>/connection.bash
rosservice call /camera_motion_demo/run '{}'
rosservice call /target/pause 'data: true'
rosservice call /target/pause 'data: false'
```

停止整个场景使用启动终端 Ctrl-C。`catkin_ws/src/uav_sim/scripts/gazebo_static.py start|status|stop` 是另一静态入口；`catkin_ws/src/uav_sim/scripts/camera_motion_command.py` 仅适用于该入口记录的活动实例，不能用于直接由 shell 启动的场景。相关说明：

## 检查与验收限制

```bash
.venv/bin/python -m pytest test/cluster/test_cluster.py test/state_machine/test_state_machine.py test/control_mux/test_control_mux.py
bash test/cluster/e2e_test/run_e2e.sh
bash test/state_machine/e2e_test/run_e2e.sh
bash test/control_mux/e2e_test/run_e2e.sh
```

三个 E2E 保留目标 develop 原入口，含固定本机路径及原进程管理方式；本轮未原样运行通过。原成果的公共隔离运行器仅保留本地，不属于本次候选。`test/uav_sim/radar_3d/` 提供实际采集和离线复算工具；`test/uav_sim/camera_motion/` 是已有红蓝标志物场景的验收工具，其中录屏区域针对固定桌面布局，不是通用8字目标验收程序。测试依赖和图形能力需在本机核对。

历史实验记录曾验证静态相机、观测机运动及三维 Ray 测距，但不构成本次整理后的重新验收。8字目标与运动观测机的完整两阶段实时录像尚未完成；目标暂停/恢复、启动入口去重及 Ctrl-C 行为仍需现场复验。已有一次观测机状态服务传输失败导致节点退出，当前代码对读取失败增加重试，尚未完成运行复验。相机实际帧率受虚拟机性能影响，不保证配置的15 Hz墙钟帧率。三维 Ray 是几何距离简化模型，不模拟完整电磁雷达。
