# Gazebo 静态场景统一入口

启动：`/usr/bin/python3 catkin_ws/src/uav_sim/scripts/gazebo_static.py start`

状态：同一命令将 `start` 改为 `status`。停止：改为 `stop`，或启动终端 Ctrl-C。
停止仅针对本入口保存并核对启动时间的进程及其创建的子进程。请勿使用全局 pkill。
同一项目的新入口通过文件锁防止重复启动；旧入口和其他项目实例不归本入口管理。

本机桌面快捷方式不纳入源码交付；如已有 `AI4静态场景.desktop`，其绝对路径需对应本机仓库。首次右键选择“允许启动”；若无该项，属性→权限→允许作为程序执行，再双击并选择“信任并启动”。桌面右键菜单如支持动作，也提供停止项。

运行固定复用 `start_static_scene.sh gui:=true dynamic_target:=false markers:=true lidar:=false`，打开 Gazebo 和 image_view 前视图像窗口。不会启动目标运动、跟踪、制导或飞控；不接受额外 launch 参数。
关闭图像窗口会结束本次场景。初始化可能需要约一分钟。

前置条件：已构建 ROS Noetic 工作区、Gazebo 11、gazebo_ros 相机插件、image_view、xdpyinfo、可访问的 X 桌面；脚本检查资源和模型引用，不自动安装或升级。
日志：`reports/unified-static-runs/<时间>-<PID>/launcher.log` 和 `scene.log`；底层 ROS 日志位置由 scene.log 开头打印，位于 `reports/static-scene-runs/`。
错误会显示具体原因及日志目录。若终端被强制 SIGKILL 或系统异常退出，自动清理无法保证；不得按过期 PID 或全局进程名清理，应人工核对日志及进程。

入口必须从源码工作树运行，根目录由脚本位置计算；现有安装声明仅安装原ROS节点与资源，两项管理CLI不安装到catkin lib目录，以免其源码树路径假设失效。切换工作树前先用旧入口停止旧实例；新树状态文件独立，不管理原工作树进程。根目录旧脚本不保留软链接。已有桌面快捷方式仅本地另行更新，历史证据保持原路径。
