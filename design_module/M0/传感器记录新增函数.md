# M0 传感器记录新增函数接口

## 1. 对外入口与返回

- prepare(root, output, config, markers=False) -> dict：验证配置并生成独立world/radar.yaml/run.json；配置非法抛ValueError。
- save_cloud(path, msg) -> int：保存组织化点云全部字段，返回有限XYZ点数；不滤掉无回波射线。
- check(root) -> dict：逐帧重开bag/NPZ比较并写verification.json；不一致抛AssertionError。
- complete(root) -> bool：判定已关闭、无错误、独立校验新鲜且所有逐帧文件存在。
- Recorder.receive(msg, topic) / write_loop() / close()：入队、单线程原消息与逐帧落盘、排空收尾；写入错误进入统计并终止。
- AuditedCluster.on_points(msg)：调用本工作区上游原回调，成功后记录收到的源帧，不修改原业务输出。
- Window(run, offline=False, self_test=False)：实时ROS联合显示，或读取本轮逐帧文件；step/seek/toggle按原测量时间和最近帧配对。

ROS参数由mounted_radar.launch传递：run_dir、world_file、observer_motion、camera_view、gui及原目标参数。脚本命令见操作说明。check_sensor_run.py/run查找器/回放脚本成功退出0，失败非0。

## 3. C++桥接与审计

sensor_source_audit.cpp 订阅Gazebo原生相机/激光扫描transport，输出测量时间CSV并发布ready参数；只审计、不改变传感器值。ray_cloud_bridge.cpp沿用原转换，仅在require_recorder=true时等待至少一个点云订阅者后订阅Gazebo源，以保证暂停期间订阅准备完成。业务节点和公共消息定义均保持上游。
