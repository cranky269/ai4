## 已知限制与未验收

真实新Gazebo预测置信度最高0.7358，常见预测面积约0.85%，不能自然满足conf>0.8、面积>0.02；未调整正式门槛。M4仍有漏检、空航迹、ID重建；最新帧主动跳帧是预期，不能把全部漏检都归因于跳帧。跟踪显示是最新航迹异步叠加，非严格同帧真值匹配。

M6正式默认640×480与实际320×240不一致，已实测中心偏差；本轮只在隔离master临时指定320/240，不代表正式配置已修复。原始yaw/z正号断言选错坐标语义，更正已记录，物理飞行方向仍未验收。

未获得T1闭环放行证据；完整T2/T3-V/T4及T5不宣称通过。飞行方向、抖动、超调、failsafe、不坠/姿态可控、全链切换延迟均未验证。既有24.7ms只代表隔离人工消息到mux的单次时延。所有错误/警告如实保留：保护性过期/无新帧告警不等于正常空检测，不写全程零告警。

本次为整理交付，未重跑Gazebo、模型或全部测试；原测试结果都有对应记录。没有必须补录的关键缺失，建议以此限定范围审阅收尾。
