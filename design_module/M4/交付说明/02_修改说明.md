| | 内容 |
|---|---|
| 原有 3 行 | `scikit-learn==1.3.2` / `scipy==1.8.1` / `pytest==8.3.5` —— **一字未改** |

### 2.2 为什么把依赖写成注释态

因为 `ultralytics` 要求 `numpy >= 1.18.5`，与文件顶部基线的
「numpy 1.17.4（系统自带，**未升级**）」**冲突**。

**若直接写成启用行**，任何人执行 `pip3 install -r requirements.txt`
都会**升级系统 numpy**，可能影响其他模块——这正是基线要避免的。

**写成注释态**后：

- `pip3 install -r requirements.txt` 的行为**与改动前完全一致**（仍是那 3 个包，系统 numpy 不动）；
- 依赖需求仍有据可查（注释里写清了包名与版本）；
- 落地方式（装到 `~/m4_deps` 独立目录、不改系统 numpy）需要群里确认后再启用。

> 详见 `03_需群里讨论事项.md` 第 2 条。**组长若认为连注释也不该加，删掉第 12–30 行即可，无副作用。**
