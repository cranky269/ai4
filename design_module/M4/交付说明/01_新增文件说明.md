## 6. ⚠️ 合并时的注意事项

### 6.1 `lib/` 下的两个文件是**链接**，不要当普通文件合并

```
catkin_ws/src/uav_tracking/lib/detector.py         ←→ code/detector.py
catkin_ws/src/uav_tracking/lib/visual_tracker.py   ←→ code/visual_tracker.py
```

与 `lib/` 下**既有 5 个文件**（`cluster.py` / `config.py` / `control_mux.py` /
`datatypes.py` / `state_machine.py`）做法**完全一致**——
已在本机验证：这 5 个文件在 `code/` 与 `lib/` 下确为**同一文件**，
我新增的 2 个也照此办理（符合 `代码书写原则.md` 第 7 条「推荐使用链接而非复制粘贴」）。

> 本机为 Windows，表现为**硬链接**；组长环境是 Linux，按原则建**软链**即可
> （注意相对路径要回到仓库根再进 `code/`）：
>
> ```bash
> cd catkin_ws/src/uav_tracking/lib
> ln -sf ../../../../code/detector.py detector.py
> ln -sf ../../../../code/visual_tracker.py visual_tracker.py
> ```
>
> 合并时请建**链接**而不是复制文件，否则后续改 `code/` 不会生效。

### 6.2 新增了两个目录

```
test/detector/            （新）
test/visual_tracker/      （新）
```

与 `test/cluster/`、`test/control_mux/`、`test/state_machine/` 同级，未改动既有目录。

### 6.3 脚本需要可执行权限

```bash
chmod +x catkin_ws/src/uav_tracking/scripts/{camera,detector,visual_tracker}_node.py
chmod +x test/{detector,visual_tracker}/e2e_test/run_e2e.sh
```

### 6.4 消息与构建文件**未改动**

`msg/` 下 7 个消息、`CMakeLists.txt`、`package.xml` **一个字都没动**。
新增的节点壳走 `rosrun` / `roslaunch` 直接运行，无需在 `CMakeLists.txt` 中登记
（与现有 `cluster_node.py` 等的做法一致）。
