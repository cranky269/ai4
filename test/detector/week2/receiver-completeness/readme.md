## 原始结果与采集边界

receivers/summary.json共16个检查，15个true，1个false（原始yaw/z正号断言）。不能汇总为16项全部通过。M8相关11个检查全部true；其余通过的是PID静默归零、空数组归零、自动恢复及真实M4数据驱动。方向断言的适用性有坐标语义疑问，按未验收交控制负责人，不删除失败或修改测试门槛凑通过。

首次脚本没收到M8启动时非锁存/state初值，直接读取空状态列表而失败；initial-harness-failure/保留日志。随后仅修审计脚本：通过实际观测SEARCH/RTH→RADAR_GUIDE建立起点，再正式计数，未改M8。正式被测M8是独立state_machine_node.py进程，不再是此前内存包装类。

受控视觉框以640×480口径给定area_ratio=0.0625；与真实bag的320×240数据严格分开。真实回放阶段已注销人工检测/视觉/雷达发布者，只回放原相机和原检测，旧航迹不回放。1266是阶段标签覆盖的观察输出数（含播放器准备等待和末端归零），不是简单20秒×50Hz的严格采样窗口，不拿它作为精确频率指标。

PID源码command_from_track在计算原始输出时就产生负yaw/z，故负值是可复现的现有行为。原消息frame=9不单独消除MAVROS转换层语义，需要控制负责人结合其设计与仿真物理方向判断。无证据不能强行宣称算法方向错误。640×480与320×240的中心不一致则已有直接源码/输入证据。
